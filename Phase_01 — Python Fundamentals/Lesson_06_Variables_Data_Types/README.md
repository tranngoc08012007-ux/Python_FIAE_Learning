# Lesson 06: Variables & Data Types

## Topics Covered
- Variable declaration with 5 core data types: `int`, `float`, `str`, `bool`, `None`
- Checking data types using `type()`
- Basic arithmetic operators: `+`, `-`, `*`, `/`, `//`, `%`
- Type casting: converting between data types (`int()`, `float()`, `str()`)
- `input()` — always returns `str`, must cast before calculations
- Advanced `print()` usage with `sep` and `end` parameters
- f-string for clean, readable formatted output

## Key Concepts

### Data Types
| Type | Example | Description |
|------|---------|-------------|
| `int` | `age = 18` | Whole numbers |
| `float` | `height = 1.75` | Decimal numbers |
| `str` | `name = "Ngoc"` | Text |
| `bool` | `is_graduated = False` | True or False |
| `None` | `note = None` | Absence of a value |

### Important Rules
- `float * int` always returns `float`
- `input()` always returns `str` — always cast when doing calculations
- `type()` returns the data type of any variable
