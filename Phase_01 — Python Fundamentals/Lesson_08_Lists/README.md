# Lesson 08: List

## Objective

By the end of this lesson, you will be able to:
- Understand how comparison operators produce boolean values.
- Use `if` / `elif` / `else`, logical operators (`and`, `or`, `not`), and the ternary expression to control program flow.
- Apply conditions to user input in simple Python programs.

## Concepts Covered

- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`) and chained comparisons
- `if` / `elif` / `else` and nested `if`
- Logical operators (`and`, `or`, `not`), precedence, and short-circuit evaluation
- Truthy and falsy values
- Ternary (conditional) expression: `value_if_true if condition else value_if_false`
- Combining `input()` with type casting and conditions
