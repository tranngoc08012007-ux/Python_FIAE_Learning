# Lesson 09: Control Flow

## Objective

By the end of this lesson, you will be able to:
- Understand how a program makes decisions using conditions that evaluate to `True` or `False`.
- Use `if` / `elif` / `else`, logical operators (`and`, `or`, `not`), comparison operators, and the ternary expression to control program flow.
- Apply conditions to user input in simple Python programs.

## Concepts Covered

- `if` / `elif` / `else` and nested `if`
- Logical operators (`and`, `or`, `not`), precedence, and short-circuit evaluation
- Truthy and falsy values
- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`), chained comparisons, and comparing strings and floats
- Ternary (conditional) expression: `value_if_true if condition else value_if_false`
- Combining `input()` with type casting and conditions
